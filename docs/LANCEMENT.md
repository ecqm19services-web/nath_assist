# Kit de lancement NUAGE — by Nath-Tech

Actions humaines obligatoires (les seules que l'IA ne peut pas faire à votre place).
Durée totale estimée : ~90 minutes, 0 € de frais fixes.

## 1. Créer les comptes (gratuits)

- [ ] **GitHub** — déjà configuré localement ; push only on explicit order.
- [ ] **Cloudflare** — Pages (hébergement du site) + R2 (10 Go gratuits, distribution des packs).
- [ ] **Google** — un seul compte ouvre : AdSense (pub récompensée), YouTube Data API (usine sommeil), Gemini API (palier gratuit).
- [ ] **Mistral « La Plateforme »** — palier gratuit pour l'assistance connectée optionnelle.
- [ ] **F-Droid** — soumission gratuite de l'APK (alternative à Google Play, 0 €).
- [ ] **Mobile Money agrégateur** (Simplifi / PayDunn / Fezi selon pays) — inscription gratuite,
      commission au succès ; nécessite pièce d'identité + RCCM (~une journée, gratuit).

## 2. Déployer

```powershell
npm run build
# puis : Cloudflare Pages → connecter ce dépôt git → dossier de sortie "dist"
```

## 3. Marque (avant toute communication)

- [ ] Vérifier « NUAGE » à l'INAPIPI (ou OMPIC/BOIP selon pays choisi).
- [ ] Réserver les domaines : nuage.app, nuage.africa, nuage.io (vérification gratuite, renouvellement payant — à arbitrer).
- [ ] Réserver les handles sociaux homonymes.

## 4. Signature

La mention **« by Nath-Tech »** est présente : titre de page, pied de page permanent,
manifeste PWA, icônes, ce document. Ne jamais la retirer d'une surface visible.

## 5. Règles d'or du produit (rappel)

- Aucun bridage du gratuit ; les extensions seules connaissent l'essai 15 jours.
- Aucune donnée biométrique ne quitte le téléphone.
- Nuage / sommeil / méditation / SOS : jamais de publicité.
- Promesse de revenus : trajectoire M+15→M+24 pour ≥ 2 M FCFA/mois, rien avant.
